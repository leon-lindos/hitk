## 已知坑

- **Claude Code 沙箱里 Go 空指针不会 panic，而是空转**：用十几行的最小程序就能复现，在沙箱外是否正常还没验证（被自动模式拦了）。后果是后端那两个 handler 包的单测会卡死，沙箱里起的后端碰到空指针也会卡住。后端单测和长期跑的预览后端，在 Leon 自己的终端里跑。
- **本机 shell 是 zsh**：
  - 变量不会按空格或换行拆开，传给命令的会是一整串。需要拆开时用 `bash -c`。
  - `--include=*.vue` 不加引号会报 no matches。
  - `$c:frontend` 里的 `:f` 会被当成修饰符。
- **前端依赖要用 pnpm 9**：`corepack pnpm@9 install --frozen-lockfile`。本机的 pnpm 11 不读 package.json 里的 overrides，和锁文件对不上。
- **Vue 组件私有样式里写深色规则要用 `.dark .x`**，不能写成 `:global(.dark) .x`，后者编译后只剩 `.dark`。
- **macOS 上装完向导后端不会自动重启**：sub2api 只在 Linux 上退出重启。本轮是用 scratchpad 里的 `run-backend.sh` 盯日志帮它重启的。
- **自动模式拦过的操作**：`git branch -f`、关掉沙箱运行、`pkill`。遇到时留给 Leon 自己处理。

## 计费调研结论（10-07）

- **两种计费方式**：
  - 按量计费：标准分组，Token 数 × 单价 × 倍率，扣余额。
  - 订阅：订阅分组设每天、每周、每月的美元上限，周和月从第一次使用起滚动 7 天、30 天；用完返回 429，不会转去扣余额。
- **在线购买**：易支付、支付宝、微信、Stripe、Airwallex，都是一次性支付。上游文档说订阅套餐「暂不支持」，这句已过时。
- **coding plan 式订阅**：
  - 已有：月费套餐、在线购买、日和周上限、限定模型、仅限 Claude Code、高峰倍率、多档套餐。
  - 缺：订阅的 5 小时窗口、按次数或提问数限额、自动续费、用完转按量计费、按套餐区分并发。
- **没有企业 / 团队这一层**：管理员能批量给一批用户开订阅，但企业客户自己没法管理员工的席位。
