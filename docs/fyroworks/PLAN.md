## 视觉基线

沿用驭火官网本地 v0.31 的品牌印章与插画，以及朱墨纸面视觉语言。

| 角色 | 颜色 |
| --- | --- |
| 纸面背景 | #F4F0E8 |
| 内容表面 | #FAF8F2 |
| 墨色文字 | #242725 |
| 辅助文字 | #61665E |
| 朱色强调 | #B63A2B |
| 细分隔线 | #D9D5CB |

标题使用 Songti SC / Noto Serif SC / Georgia；表单、导航和数据使用系统无衬线字体。首页和登录页承接印章、留白、手绘素材；控制台延续纸面和朱墨配色，保持表格密度与操作可读性。深色模式使用暖墨背景和浅色文字。

```text
首页：品牌与导航 → 服务说明与进入控制台 → 接入功能 → 页脚
登录：驭火品牌与手绘插画 | 登录表单与账号入口
控制台：品牌侧栏 | 顶部导航 / 页面标题 / 原有业务内容
```

设计核对：暖纸色与宋体来自已有驭火素材；视觉识别集中于印章和朱色，正文和业务表格保持清晰。文案仅描述现有功能。品牌配置继续支持站点管理员自定义。
